# Changelog

All notable changes to CWT (Can's WhatsApp Tool) will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [1.0.0] - 2026-02-08

### Added
- Initial release of CWT Chrome extension
- Export WhatsApp Web chats to HTML format
- Export WhatsApp Web chats to TXT format
- Export WhatsApp Web chats to JSON format
- Support for text messages with sender names and timestamps
- Support for media files (images, videos, audio, documents)
- Beautiful popup UI for format selection
- Export button integrated into WhatsApp Web interface
- Progress indicator during export
- Privacy-focused design with 100% local processing
- Comprehensive README documentation
- Installation guide
- Privacy policy
- Contributing guidelines
- MIT License
- Extension icons (16px, 48px, 128px)

### Features
- 🔒 100% local processing - no external servers
- 🚫 Zero tracking or analytics
- 📥 Multiple export formats (HTML, TXT, JSON)
- 🖼️ Full media support
- ⚡ Fast message extraction
- 🎨 Styled HTML exports
- 🌐 Open source
